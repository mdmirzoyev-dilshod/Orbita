# Раздел «Задачи» в «Орбите» — описание (на 04.11.2026)

## Поля задачи
- Название (до 200 символов), описание (до 2000).
- Исполнитель, автор (кто поставил), компания.
- Приоритет: высокий / средний / низкий.
- Срок: дата + необязательное время «до ЧЧ:ММ» (без времени — до конца дня).
- «Напомнить в Telegram»: дата и время (необязательно).
- Чек-лист: до 20 пунктов, отмечаются на сайте и кнопками в боте.
- «Нужен фото-отчёт»: задачу нельзя закрыть кнопкой «Сделал» без фото.
- Повтор: каждый день / по будням / по дням недели / каждый месяц (в число срока); задачи серии создаются сами в 06:00.
- Служебные поля: дата создания и выполнения, сколько раз продлевали, «видел» (время), «напомню в», «напоминания выключены», «просил больше времени».
- Комментарии: текст, голосовые (расшифровка с 🎙), фото. История продлений пишется в комментарии.

## Статусы
Новая → В работе → На проверке → Выполнено.
«Просрочено» — не статус, а признак: срок (дата и время) прошёл, а задача не выполнена.

## Роли и права
| Роль | Что видит | Ставит задачи |
|---|---|---|
| Владелец, Учредитель, Директор (руководство) | Всю компанию | Всем |
| Руководитель отдела | Свою ветку подчинения и сотрудников своего отдела | Им и себе |
| Сотрудник | Свои задачи | Только себе |

- Менять, удалять и продлевать задачу может автор или руководство. Исполнитель продлить себе срок не может — только «⏳ Нужно больше времени».
- Учредитель никому не подчиняется.

## Экраны сайта
- **«Командный центр»** (руководитель): в работе, горит, вовремя за 30 дней, личные планы; рейтинг дисциплины; лента событий; созвездие команды; «Требует решения» (+2 ч / +1 день / +3 дня); повторяющиеся задачи; срок сегодня.
- **«Задачи»**: вид «Сроки» (шкала по дням с нагрузкой) и «Доска» (колонки по статусам), фильтр по сотруднику, поиск. У сотрудника — «Мои задачи»: Просрочено / Сегодня / Скоро / Выполнено.
- **Окно задачи**: поля, статус, чек-лист, фото-отчёты, повтор («Остановить повтор»), блок напоминаний, продление срока, комментарии.
- **«Поставить задачу»**: что сделать, подробности, исполнитель, приоритет, срок и время, повтор, напоминание, чек-лист, «Нужен фото-отчёт».
- Тёмная тема по умолчанию, переключатель «День / Ночь». Сайт обновляется сам без перезагрузки (синхронизация с ботом).

## Telegram-бот (@OrbitaUzbot)
- Новая задача приходит с кнопками: 👍 Принял, ✅ Сделал, ⏳ Нужно больше времени, кнопки чек-листа.
- Ответ на сообщение о задаче (текст или голос) — комментарий; фото ответом — фото-отчёт.
- Задачу можно поставить голосом или текстом («Мадине до завтра в 15:00 отчёт, срочно») — черновик с кнопками «Поставить / Другой исполнитель / Отмена».
- Отметка на сайте меняет кнопки в сообщениях бота на «✅ Выполнено» (и наоборот).

## Напоминания
| Когда | Кому | Кнопки |
|---|---|---|
| Утренняя сводка и вечерние итоги (по умолчанию 08:00 и 21:00, настраивается) | Каждому | — |
| «Скоро срок» — за 1 ч, 2 ч (по умолчанию) или за день | Исполнителю | ✅ Сделал · 👀 Видел, помню · ⏰ Напомнить позже (15 мин / 1 ч / 3 ч / завтра 9:00 / не напоминать) · ⏳ Нужно больше времени |
| В заданное время («Напомнить в») | Исполнителю | те же |
| «Срок истёк» | Исполнителю; автору (или его руководителю) | Автору: +2 ч / +1 / +3 / +7 дней |

- Отложенные напоминания приходят один раз и отменяются, когда задача выполнена.
- На сайте в окне задачи те же действия: +15 мин, +1 час, Завтра 9:00, выключить / включить напоминания.
